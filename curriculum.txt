Stage 1.1 — Stabilize + Walk to Ball Contact
Environment:
    Ball spawned 0.5-1m in front of robot, height = 0.3m (H_F, locked constant).
    Ball Z-axis constrained via per-step event clamp (zero XY vel + position snap to anchor).
    No kick objective yet — goal is stable locomotion up to first foot-ball contact.
Rewards:
    termination_penalty - when robot falls
    orientation_penalty (flat_orientation_l2) - penalize tilt
    lin_vel_z_l2 - shud be ~0
    dof_pos_limits - ankle joint limits
    joint_deviation_hip - same as for walking
    joint_deviation_arms - same as for walking
    joint_deviation_torso - same as for walking
    feet_slide - penalize foot sliding while in contact with ground
    track_ang_vel_z_exp - penalize yaw drift
    track_lin_vel_xy_to_ball_exp - reward velocity that closes the gap to ball in 0.5s
    ball_robot_dist (exp shaping) - low weight, near-flat gradient over range, kept small on purpose
    dist_to_ball_raw - linear distance penalty (NOTE: currently unnegated with positive weight — must flip sign, rewards moving away from ball as-is)
    feet_air_time - reward only air time between 0.2-0.5s (NOTE: needs single_support gate to block double-hop hacking)
    foot_front_height_reward - reward foot positioned in front of base at kick-ready height/angle
    ball_foot_contact - small weight, first-contact discovery only
    ball_illegal_contact_penalty - pelvis/torso/knee touching ball
    ball_vel_z / apex_height / ball_vel_xy - weight 0.0 (ball is Z-constrained, no flight yet)
Transition gate:
    success rate - 90% in 100 iterations
    success metrics -
    - consistent foot-ball contact achieved, no falls
    - orientation/torso height stay in bounds for full episode
    - episodes terminate due to time (25s, per H1JuggleEnvCfg.episode_length_s)
Terminations:
    robot falls - torso <0.3
    episode length - run time < 25s
    robot_out_of_bounds - robot-ball XY distance > 10m

Stage 1.2 — Natural Kick Discovery
Environment:
    Ball spawn distance fixed to 0.5-1m (replaces current 5m placeholder in reset_ball_state — confirmed open bug).
    Height 0.3m (H_F), still Z-axis constrained.
    No prescribed impulse/kick shape — reward contact and let policy discover the kicking motion naturally.
Rewards:
    Same set as Stage 1.1, plus:
    ball_foot_contact - weight increased vs. 1.1
    ball_vel_z_reward - reward any upward impulse generated on contact (ball still Z-constrained, so this only shapes vertical response, not drift)
    ball_illegal_contact_penalty - unchanged
Transition gate:
    success rate - 90% in 100 iterations
    success metrics -
    - >=15 legal ball_foot_contact events per episode
    - ball_illegal_contact_penalty ~0
    - episodes terminate due to time (25s)
Terminations:
    robot falls - torso <0.3
    episode length - run time < 25s
    robot_out_of_bounds - robot-ball XY distance > 10m

Stage 2 — Balloon Ball, Free Vertical Kick
Environment:
    Z-axis constraint removed (constrain_ball_to_z_axis event disabled) — ball free to fly on contact.
    Ball given balloon-like properties (reduced effective mass / higher drag) as an intermediate step before the final 0.45kg ball.
    Locked physics constants apply: M_B = 0.45kg (final target), apex target height = 1.2m ± 0.4m (band 0.8-1.6m), H_F = 0.3m, g = 9.81.
Rewards:
    Full Stage 1.2 set, plus:
    ball_vel_z_reward - shape upward launch velocity
    apex_height_reward - reward apex within 0.8-1.6m band (NOTE: current code still bands 1.5-2.5m — must be re-banded to match locked constant before this stage is valid)
    ball_vel_xy (track_ball_vel_xy_exp) - penalize horizontal drift now that Z-constraint is off
Transition gate:
    success rate - 90% in 100 iterations
    success metrics -
    - >=10 legal contacts per episode
    - apex height within 0.8-1.6m band
    - ball_vel_xy drift near-zero
    - episodes terminate due to time (25s)
Terminations:
    robot falls - torso <0.3
    episode length - run time < 25s
    robot_out_of_bounds - robot-ball XY distance > 10m
    ball_ground_contact + delay (2s) - to be added, not yet implemented

Stage 3 — Domain Randomization for Deployment
Environment:
    Balloon properties removed — full 0.45kg ball.
    Randomized ball spawn distance/angle/height within trained bands.
    Randomized ground friction/restitution.
    Randomized initial robot pose perturbations, sensor/actuator noise for sim-to-real robustness.
Rewards:
    Same full set as Stage 2; weights re-tuned/annealed per randomization difficulty.
    Alternate-foot bonus (optional) - reintroduce only if multi-contact juggling behavior is targeted beyond single-kick reliability.
Transition gate:
    success rate - 80% in 100 iterations, across randomized conditions
    success metrics -
    - >=2 legal contacts per episode
    - apex height within band
    - illegal contact penalty ~0
    - episodes terminate due to time (25s)
Terminations:
    robot falls - torso <0.3
    episode length - run time < 25s
    robot_out_of_bounds - robot-ball XY distance > 10m
    ball_ground_contact + delay (2s)
